# 个人索引式作品集改版设计

## 目标

把当前“面向不同身份的两张概念海报”改为一个更接近技术创作者主页的个人索引。首页在一屏内让陌生访客知道这个人是谁、在做什么、有哪些可点开的成果；工程和研究简历保留为两个面向明确的辅助页面。

## 参考原则

借鉴 Anthony Fu 的信息组织：直接身份说明、公开项目索引、写作/演讲等持续输出与统一外链；不复制其源代码、文案、组件或视觉资产。借鉴其“事实比形容词更有说服力”的表达，不写“把 AI 做成可交付系统”“让模型经得起追问”之类自我定义口号。

## 路由

- `/`：主入口。包含个人简介、正在做、精选项目、论文与研究、最新输出、全部链接。
- `/resume-engineering/`：一页式工程简历，按工作经历、项目、技术能力、开源/写作排序，可打印。
- `/resume-research/`：一页式研究简历，按研究兴趣、发表、教育与研究经历、技术能力排序，可打印。
- 旧的 `/engineering/` 与 `/research/` 重定向或显示清晰的迁移链接，避免旧书签失效。

## 文案

主标题使用人名，副标题为短事实句，例如“AI 应用工程师，关注 Agent、RAG 与语言智能”。每张内容卡片采用“做的事 + 可打开的证据”，不做形容词堆叠。企业经历只保留可公开的职责；开源项目与论文优先链接到 GitHub 和正式出版页；博客、B 站、公众号作为持续输出渠道呈现，不伪造数据。

## 视觉

白色或近白背景、深灰文字、单一蓝绿色强调；页面宽度适中，左侧在桌面端固定为个人信息与导航，右侧是时间顺序的内容流。标题大小回到正常阅读尺度，使用清晰的无衬线正文和紧凑的等宽元数据。没有全屏口号、页面入场动画、装饰网格或大面积色块；轻微 hover 与 focus 仅用于可点击性反馈。

## 交互与可访问性

首页导航锚点滚动到相应区块，外部链接新标签打开并标识；键盘焦点明显；手机端把固定侧栏移到顶部，内容单列。页面无需 JavaScript 也能阅读主要内容，JavaScript 只用于渲染重复的公开资料。

## 验收

1. 首页十秒内可见姓名、定位、至少两个公开成果链接与工程/研究简历入口。
2. 每个项目和论文都有直接来源或明确的“整理中”状态，不包含内部资料。
3. 两份简历的内容顺序不同，分别服务招聘者和导师，而不是同一页换标题。
4. 375px 宽度和桌面宽度均无横向滚动，键盘能访问所有链接。
